# 服务部署操作文档

## 部署命令
```shell
# rz命令下载
yum -y install lrzsz

chmod +x docker.sh
# win和linux字符引起的错误
sed -i 's/\r$//' docker.sh
nohup sh docker.sh >my.log 2>&1 &
tail -f my.log
```

## minio 导出文件
```shell
cd /opt/docker/minio
./mc alias set local http://172.18.0.11:9000 minio minio-960@*
./mc mirror local/blog ./files
cd files
zip -r files.zip ./*
sz files.zip
```
